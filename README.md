# C1747-Project-1
Genome sequencing project that investigated the effects of genotoxic agents on yeast. First, reads were validated through defining correct length and valid characters and standardizing input as upper case. Then, mutations were found and recorded and analysis summaries were made based on validity status and final summaries that recorded mutation frequency and ran a Welch's two-sided t-test on a larger dataset. The results showed that at positions 97, 98, and 99; there were the most mutations not found in the control sample, and were mostly switches from C to A or A to C, indicating the purine/pyrimidine switch may be the underlying mechanism of how that particular agent damages DNA.
